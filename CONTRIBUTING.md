# Contributing

This repository is the public GitHub landing page for Buda.

Good contributions include:

- Fixing broken links
- Improving README clarity
- Suggesting better screenshots or gallery ordering
- Improving ICP directory wording
- Reporting outdated release-note, docs, or marketplace links

Please keep contributions focused on public-facing materials. Product bugs, account issues, and security reports should go through the channels listed in README.md and SECURITY.md.
